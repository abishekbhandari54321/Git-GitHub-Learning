# Day 8 - Homework

## Task 1 - Fork and Clone

1. Fork a public GitHub repository.
2. Clone the forked repository to your computer.
3. Verify that the repository exists locally.

Command:

git clone <repository-url>

---

## Task 2 - Create Issues

Create at least three issues:

1. Add a new feature
2. Fix a bug
3. Improve documentation

---

## Task 3 - Add Labels

Add appropriate labels:

Feature Issue → enhancement

Bug Issue → bug

Documentation Issue → documentation

---

## Task 4 - Assign Issues

Assign at least one issue to yourself.

---

## Task 5 - Create a Project Board

Create a project board with:

To do

In Progress

Done

Move the issues through the workflow:

To do → In Progress → Done

---

## Task 6 - Create a Milestone

Create a milestone:

Version 1.0

Add multiple issues to the milestone.

Close the issues and observe the milestone progress.

---

## Task 7 - Create Issue Relationships

Practice:

- Add parent
- Mark as blocked by
- Mark as blocking

Understand how issues can depend on each other.

---

## Task 8 - Create a Discussion

Create a GitHub Discussion using the Q&A category.

Ask a question related to software development.

---

## Task 9 - Practice Filters

Practice these filters:

label:bug

is:open

is:closed

Combined filter:

label:bug is:open

---

# Goal

Understand how GitHub is used not only for storing code, but also for:

- Planning work
- Tracking tasks
- Managing bugs
- Organizing releases
- Communicating with developers
- Managing open-source projects
