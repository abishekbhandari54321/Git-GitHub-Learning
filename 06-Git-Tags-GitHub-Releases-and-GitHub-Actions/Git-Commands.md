# Git Commands - Tags, Releases and GitHub Actions

## Create a Tag

```bash
git tag v1.0
```

Creates a tag named `v1.0`.

---

## View All Tags

```bash
git tag
```

Shows all tags in the repository.

---

## Push a Tag to GitHub

```bash
git push origin v1.0
```

Uploads the tag to GitHub.

---

## Push All Tags

```bash
git push --tags
```

Uploads all local tags to GitHub.

---

## Delete a Local Tag

```bash
git tag -d v1.0
```

Deletes a tag locally.

---

## Delete a Remote Tag

```bash
git push origin --delete v1.0
```

Deletes a tag from GitHub.

---

## Check Repository Status

```bash
git status
```

Shows the current status of the repository.

---

## Add Changes

```bash
git add .
```

Adds all changes to the staging area.

---

## Commit Changes

```bash
git commit -m "message"
```

Creates a new commit.

---

## Push Changes

```bash
git push
```

Uploads commits to GitHub.
